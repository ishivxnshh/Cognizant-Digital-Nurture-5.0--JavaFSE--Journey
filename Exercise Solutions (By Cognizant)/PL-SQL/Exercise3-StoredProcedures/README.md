# Exercise 3: Stored Procedures

## Overview
This exercise focuses on PL/SQL stored procedures for banking operations including interest processing, bonus updates, and fund transfers.

## Scenarios

### Scenario 1: Process Monthly Interest
- File: `Scenario1_ProcessMonthlyInterest.sql`
- Procedure: ProcessMonthlyInterest
- Task: Calculate and update the balance of all savings accounts by applying 1% interest rate to the current balance

### Scenario 2: Update Employee Bonus
- File: `Scenario2_UpdateEmployeeBonus.sql`
- Procedure: UpdateEmployeeBonus
- Task: Update the salary of employees in a given department by adding a bonus percentage passed as a parameter

### Scenario 3: Transfer Funds
- File: `Scenario3_TransferFunds.sql`
- Procedure: TransferFunds
- Task: Transfer a specified amount from one account to another, checking for sufficient balance in the source account before making the transfer
