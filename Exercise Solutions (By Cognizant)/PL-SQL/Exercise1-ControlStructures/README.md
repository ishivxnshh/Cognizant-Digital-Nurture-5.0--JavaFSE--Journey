# Exercise 1: Control Structures

## Overview
This exercise focuses on PL/SQL control structures and loops for banking operations.

## Scenarios

### Scenario 1: Loan Discount for Customers Above 60 Years Old
- File: `Scenario1_LoanDiscountForSeniors.sql`
- Task: Apply a 1% discount to loan interest rates for customers above 60 years old

### Scenario 2: VIP Promotion Based on Balance
- File: `Scenario2_VIPPromotion.sql`
- Task: Set IsVIP flag to TRUE for customers with balance over $10,000

### Scenario 3: Loan Reminders for Due Loans
- File: `Scenario3_LoanReminders.sql`
- Task: Send reminders to customers whose loans are due within the next 30 days
